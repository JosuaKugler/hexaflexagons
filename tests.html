Paper check

The automatic checks can only test the model against its own physical rules. To test it against reality, fold a hexahexaflexagon from the template on the main page and compare:

  1. Fold the strip, start with face 1 on top and face 2 underneath (the main page's "Start again" state).
  2. Choose V-flex and leave the first crease selected. Note the two marked corners; on paper, mark them the same way.
  3. Follow the four steps. After each one, compare what you hold with the 3D view; the shapes listed below are what the model predicts.
  4. When it lies flat again, compare each sector with the table below. A single wrong face, or a picture turned differently, means the model and the paper disagree.
